# PKU Lv9 数组实验报告（实现完成，远程验收仍进行中）

从最终 Lv8 `99928b9` 建立独立分支 `edidada/lv9-array`，每个实验使用独立的 `lv9-array.yml`。本地只做静态修改；编译和实验全部在 GitHub Actions。

## 已实现行为

支持多维声明、递归初始化列表、运行期初始化表达式、索引左值/右值、首维省略的数组形参和子数组实参。按尾维对齐补零，保留显式表达式求值顺序；未初始化局部数组不补零。维度、索引、只读数组和调用形状均检查；先前形参遮蔽全局常量时，不会误用外层常量解析后续维度。

IR 保留数组形状、存储位置和只读信息；全局为有类型 aggregate/zeroinit，局部按实际尺寸分配。Koopa 使用 getelemptr/getptr 与间接 load/store；RV32 指针固定4字节，栈16字节对齐，支持超8参数、递归及大帧。

## 性能修改

临时值读写在偏移<=2047时使用 RV32 直接栈寻址；更大偏移保持展开地址。纯隐式补零且至少64元素的局部数组改用循环：从第一个标量元素出发，以 getptr 步进逐个写0，避免逐元素展开产生大量永久 spill 槽。显式初始化表达式保持原路径，不对测试名做特殊处理。99数组回归中的大数组先检查全部初始0；多维循环内数组先读取零值再写99，验证下一轮重新清零。
